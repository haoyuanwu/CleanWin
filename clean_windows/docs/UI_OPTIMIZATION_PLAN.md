# CleanWin 页面与交互优化计划

## 后续调整：概览与清理合并

按最新需求，原概览页与一键清理合并为「概览与清理」，只保留一个侧栏入口。
原概览页的快捷功能和重复扫描结果区已移除，旧索引 1 兼容跳转到合并页，其他模块
的索引保持稳定。半叠放侧栏继续保留。

- 未扫描：显示真实磁盘概况、开始扫描、管理员扫描；不展示 0 B 结果、结果筛选或清理栏。
- 本次启动尚未扫描时，恢复的旧缓存也不自动显示为当前扫描结果。
- 扫描中：显示实时路径与平滑进度，完成的分类依次渐显并轻微上移，数量平滑变化。
- 结果：分类默认折叠，显示数量、占比、可预览/手动确认/未完整读取状态，展开箭头跟随动画。
- 固定底部选择栏展示已选数量与空间，扫描完成后才允许清理；扫描失败有明确状态提示。
- 动画支持系统减少动态效果设置，关闭尺寸动画时直接布局，避免零时长布局断言。

新增测试覆盖未扫描页面、旧缓存隐藏、逐类动画、默认折叠与减少动态效果。
预览更新为 `.dart_tool/ui_previews/clean-idle.png` 与 `clean-results.png`（模拟数据）。
以下为前一轮优化记录；涉及概览和一键清理分立的描述以本节为准。

目标：保留靛蓝与青色品牌、深色侧栏，降低背景干扰，建立清晰的信息层级。

## 执行范围

1. 导航：工作台（概览）；空间清理（一键清理、磁盘分析、大文件、下载管理）；
   系统管理（运行优化、软件卸载、启动项、注册表）；偏好与保护（白名单、设置）。
   分组滚动，选中高亮，切页保留任务状态。
2. 通用布局：统一标题、说明、可换行操作区，浅色内容卡片、明确表头、可读弹窗。
   所有模块有清楚的名称，主要操作与内容区分层。
3. 概览：修正软件卸载跳转；扫描立即进入进度页；磁盘显示真实容量信息。
4. 一键清理：汇总发现、勾选、异常分类；分类搜索与只看有结果筛选，默认折叠保留。
5. 磁盘分析：返回、停止、可换行磁盘工具；防止旧任务覆盖新路径结果。
6. 大文件：真实盘符、结果搜索、切换范围清除旧结果、删除忙碌状态和失败反馈。
7. 下载：名称/路径搜索、大小优先；明确已选数量，删除仅作用于下载分类。
8. 运行优化：统一页面标题与操作区，增加暂停/继续实时刷新，保持内存排序。
9. 软件卸载：保留进入自动扫描；支持名称/大小排序、搜索清空、失败提示。
10. 启动项：名称/命令查找、启用状态筛选、操作中防止重复提交。
11. 注册表：名称/路径搜索、清空选择、扫描时清除旧选择，清理忙碌状态。
12. 白名单：统一页面头部、路径搜索，操作入口集中，继续保留移除确认流程。
13. 设置：统一头部，设置生效说明，移除没有操作的跳转箭头。

## 一键扫描范围与默认勾选（2026-10-17）

- 一键扫描仅检查当前用户的系统缓存、浏览器缓存、软件缓存和显卡缓存。跳过系统维护目录、安装目录、注册表、下载文件与使用记录，减少重复和无效遍历；不再逐个提取软件图标。
- 显示结果前在后台核对删除权限，排除占用、只读、系统、脱机及链接文件。检查只打开并关闭文件句柄，不修改或删除文件；实际清理仍重新执行原有安全检查。
- 默认仅勾选七天前的 `.tmp/.temp` 临时文件，包括重定向 TEMP/TMP。浏览器、软件、显卡、缩略图等重建类缓存需手动选择；避免默认触发缓存重新加载或着色器重新编译。
- 更新扫描缓存版本，旧扫描结果不会恢复较宽松的默认选择。移除概览的管理员扫描入口，设置中的缓存扫描开关明确说明默认不选中。
- 静态检查通过；全量 110 项测试通过。新增覆盖权限、占用和只读排除、默认选择、旧结果恢复及重定向临时目录。未删除实际用户文件，需重新编译运行后生效。
- 默认选择依据：[Google 缓存清理说明](https://support.google.com/accounts/answer/32050?hl=En)、[NVIDIA 着色器缓存说明](https://www.nvidia.com/content/Control-Panel-Help/vLatest/en-us/mergedProjects/3D%20Settings/Manage_3D_Settings_%28reference%29.htm)；权限核对依据：[Microsoft CreateFileW](https://learn.microsoft.com/zh-cn/windows/win32/api/fileapi/nf-fileapi-createfilew)。
