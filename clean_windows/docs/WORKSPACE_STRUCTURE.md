# CleanWin 产品重构：以任务归属组织功能

## 产品目标

用户在空间清理、个人文件整理、系统诊断、应用管理之间切换时，每项能力只有一个主要操作入口。清理大小只代表可审查的清理对象，硬件信息、网络状态、软件数量不再出现在清理结果里。

## 导航和工作区

| 侧栏分组 | 主入口 | 工作区标签 | 数据职责 |
| --- | --- | --- | --- |
| 空间与文件 | 概览与清理 | 宇宙概览、分组清理结果 | 缓存、临时文件、诊断文件、使用痕迹、回收站 |
| 空间与文件 | 文件管理 | 磁盘分析 / 大文件 / 下载审查 | 目录占用、按大小查找、按下载来源审查个人文件 |
| 系统与应用 | 系统监控 | 运行监控 / 硬件信息 / 网络诊断 | 实时资源和进程、设备配置、网络与代理诊断 |
| 系统与应用 | 应用管理 | 软件卸载 / 启动项 / 应用残留 | 软件生命周期、可管理自启动、安装目录空文件夹 |
| 系统与应用 | 系统维护 | 注册表 / Windows 设置 | 可处理的失效登记、默认应用和 Windows 偏好 |
| 保护与偏好 | 白名单 | 排除项管理 | 所有清理共用的保护规则 |
| 保护与偏好 | 设置 | CleanWin 自身偏好 | 自动扫描、扫描选项、应用行为 |

侧栏从十个独立功能入口收敛为七个主入口。相关详情页进入同一工作区，避免侧栏越来越长。选中的标签和已经访问的页面状态会保留；未访问的页面不提前创建。运行监控仅在当前标签可见时采样。

## 全部清理扫描项的唯一归属

| 扫描项 | 主入口 | 处理与选择 |
| --- | --- | --- |
| 系统临时文件与可重建缓存 | 概览与清理 / 缓存与临时文件 | 仅旧的可操作临时文件可自动选中 |
| 浏览器缓存 | 概览与清理 / 缓存与临时文件 | 默认勾选 |
| 已安装软件缓存 | 概览与清理 / 缓存与临时文件 | 通用发现和软件规则共同覆盖，默认勾选 |
| 显卡着色器缓存 | 概览与清理 / 缓存与临时文件 | 不默认勾选，说明重建代价 |
| 更新缓存 | 概览与清理 / 缓存与临时文件 | 仅显式扫描产生结果时展示，不扩大默认扫描 |
| 系统与软件诊断日志 | 概览与清理 / 日志与痕迹 | 默认勾选，执行前确认 |
| Windows 最近记录与跳转列表 | 概览与清理 / 日志与痕迹 | 默认勾选，不删除原始文档 |
| 软件使用记录 | 概览与清理 / 日志与痕迹 | 仅显式扫描产生结果时展示，默认勾选 |
| 回收站 | 概览与清理 / 个人文件 | 统计当前用户回收站实际大小，默认勾选，永久删除前确认 |
| 系统和软件管理器下载目录 | 文件管理 / 下载审查 | 不纳入概览扫描、大小和清理；按来源分组，用户选择后移入回收站 |
| 应用残留 | 应用管理 / 应用残留 | 新独立审查页，仅可操作空目录；原有安全清理服务在删除前复核 |
| 注册表无效项 | 系统维护 / 注册表 | 使用原专用扫描器、可清理过滤与备份流程；不在概览复制另一份清单 |

旧规则快照不再恢复，需按当前范围重新扫描。展示和清理入口均按归属隔离：即使下载页选中了文件，概览的星球、合计、确认弹窗和实际删除范围也不包含它们。

内存转储不再进入扫描、概览或清理范围。概览候选默认勾选，唯一例外是显卡缓存；下载、应用残留和注册表继续由各自的独立审查入口管理。

## 原全面体检的拆解

| 原检查 | 新归属 | 重构决策 |
| --- | --- | --- |
| CPU / 物理内存 / 主板 / 显卡驱动 / 磁盘型号 / 网卡 / 声卡 / 显示器 / Windows 版本 | 系统监控 / 硬件信息 | 启动后静默读取一次，专用详情页直接回显，可手动刷新 |
| 系统连通性 / IP / 子网 / 网关 / DNS / DHCP / 系统代理 / 代理环境变量 | 系统监控 / 网络诊断 | 启动后静默读取本机配置；隐藏 URL 中的凭据 |
| 外网 DNS / 延迟 / 未响应比例 | 系统监控 / 网络诊断 | 保留主动检测前的外网请求确认 |
| DNS 缓存刷新 / 网络、代理、疑难解答设置 | 系统监控 / 网络诊断 | 保留独立操作和 DNS 刷新确认，不作为自动修复 |
| 磁盘可用空间 | 文件管理 / 磁盘分析、概览磁盘卡 | 使用现有来源，不再启动重复的体检脚本 |
| 可用内存 | 系统监控 / 运行监控 | 使用实时采样，不再读取第二份体检内存 |
| 最近文件快捷方式 | 概览与清理 / 使用痕迹 | 使用实际可操作扫描快照，不再额外统计快捷方式 |
| 桌面软件数量 | 应用管理 / 软件卸载 | 使用现有完整清单，移除重复登记统计入口 |
| 可管理启动项数量 | 应用管理 / 启动项 | 使用现有可切换启动项清单，移除重复脚本扫描 |
| 默认浏览器 / PDF 关联 / 任务栏 / 锁屏 / 通知 | 系统维护 / Windows 设置 | 启动后静默读取，专用设置检查页回显；通过固定 Windows 设置入口调整 |

原全面体检聚合页面不再挂载到产品导航或概览。底层旧全量检查接口保留兼容测试和已有调用；生产页面仅请求自身 hardware / network / preferences 检查，不运行 storage / applications 聚合脚本。

## 数据与生命周期

- `workspace_structure.dart` 集中定义导航、深链接、清理与诊断的归属。
- 原 3（大文件）、8（下载）、6（启动项）等入口定位到对应工作区标签；原 1 / 11 兼容进入概览。
- 新详情路由 12（硬件）、13（网络）、14（应用残留）、15（Windows 设置）。
- `WorkspaceTabs` 首次进入时创建页面，之后用 IndexedStack 保留状态与滚动位置。
- 清理扫描状态和取消仅影响文件扫描。硬件/网络检查由独立控制器负责，支持取消、错误提示、部分结果保留；不会阻塞清理按钮等待 WMI。
- 硬件、网络和偏好共享已读取结果，但刷新只执行当前页脚本。复制报告也仅复制当前页内容。
- 安全流程保持：白名单、可操作性检查、快照复核、清理前确认、清理取消、实际释放与移入回收站区分。

## 验证

覆盖功能归属、旧入口跳转、按需扫描、切页不重扫、未访问页不初始化、标签输入保留、下载选择不进入概览清理、窄窗口与桌面布局、系统检查空态/忙态/结果。视觉测试使用夹具，不扫描或清理真实用户文件。


## 启动时静默读取

每次软件启动自动读取 hardware / network / preferences 一次，结果仍保留在各自工作区。读取不依赖“启动时自动清理扫描”开关，不修改清理扫描的忙态和进度，不跳转页面、不弹窗，也不展示扫描进度条。用户进入详情页时已完成的内容直接显示，尚未完成时显示简短读取状态。实时 CPU / 内存 / 进程监控保持进入页面后按秒采样，不在后台持续轮询。

自动读取不执行外网探测、DNS 刷新或设置修改；失败通过各页的未读取状态呈现，并可手动刷新。切换工作区或重建外壳不会重复发起启动读取。


系统监控补充：进程管理现为第四个独立标签（深链 16），资源概览不再内嵌进程表。运行监控呈现 CPU/内存/温度/上下行吞吐；硬件配置采用本机快照大屏。原硬件、网络深链与索引保留，切换页面继续遵循惰性创建、状态保留、非活动页停止轮询。

系统维护取舍：Windows 设置使用直接工具页，不再显示偏好建议或启动时读取建议。注册表维护独立处理七类可验证失效值与备份恢复。删除任务与记录页面及全部入口；系统监控中的立即加速负责后台工作集和七天前临时文件的分析确认，其他垃圾/下载/系统组件仍各归原模块。
