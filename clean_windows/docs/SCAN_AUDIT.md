# 扫描范围与清理边界

2026-10-20。扫描只读取候选，清理只操作已勾选文件快照；结果列表默认折叠。

## 一键扫描

默认扫描系统缓存、浏览器缓存、软件缓存、显卡缓存，以及当前用户回收站和下载文件夹。系统维护类别仍不参加默认扫描。回收站与下载默认不勾选；明确勾选后可通过智能清理处理，并始终要求确认。

| 分类 | 范围与规则 | 默认勾选 |
|---|---|---|
| 系统缓存 | 当前用户临时目录、重定向 TEMP/TMP、缩略图等可重建缓存；跳过危险根目录及不可操作内容 | 仅 ≥7 天且可操作的 .tmp/.temp 临时文件；其余不勾选 |
| 浏览器 | Chrome/Edge 及测试渠道、Firefox、Brave、Chromium、Vivaldi、Opera 的明确缓存；支持多配置，保留 Cookie、密码、书签 | 否 |
| 软件缓存 | 快速模式检查已知 Code、Discord、Slack、Spotify、Teams 缓存；一键深度模式在用户 AppData 内按明确缓存名发现，最多 6 层；服务的定向软件扫描最多 8 层 | 否 |
| 显卡缓存 | 当前用户 DirectX、NVIDIA、AMD 缓存；重建可能导致游戏首次使用卡顿 | 否 |
| 回收站 | 仅就绪本地／可移动磁盘中当前用户 SID 的已扫描文件，不处理其他账号；手动清空前必须确认永久删除 | 否 |
| 下载文件夹 | Windows 已知下载位置及默认 Downloads 中 ≥10MB 的文件／目录；腾讯 QMDownload/SoftMgr、360Downloads/Software 等明确下载目录及支持注册表项中配置的下载位置，下载包不设 10MB 门槛，按来源汇总 | 否 |

软件下载只按 exe、msi、msix、appx、zip、7z、rar、cab、iso、apk 等明确包格式列出。QMDownload 根目录只检查直接文件，不递归 Hotfix；不将安装目录、配置文件及未完成下载当作软件包。不递归搜索全盘任意 Download 文件夹；未识别版本或未记录的自定义位置仍可能遗漏。

关闭浏览器或显卡扫描选项后，通用软件缓存不会绕过选项。开发依赖、离线资源、安装修复资料及本程序缓存受保护。深度模式的缓存名称只是候选线索，不能代表内容一定可以无影响地删除。

## 独立或兼容分类

扫描服务保留系统日志、空安装目录、转储、更新缓存、注册表、使用痕迹及软件使用记录的定向扫描能力，但它们不属于默认一键扫描。下载管理与一键扫描共用下载发现规则，默认不勾选；文件移入回收站，容量不冒充实际释放空间。注册表页面仅列出支持安全处理的失效值，分类折叠，不整键清理。

非一键定向扫描可能涵盖系统位置；权限不足、服务占用、只读及变化内容均跳过。系统维护分类不等同于无风险清理建议，默认不勾选。

## 共用保障

- 分目录遍历，读取失败后继续其他目录；提示未完整读取的位置。
- 权限按最多 256 个路径一批在后台核对，实时显示阶段和路径，支持取消。
- 无操作权限、占用、只读等文件不列入可清理结果，分类提示已跳过数量。
- 保存文件清单、大小及修改时间；清理前再验证变化、链接、白名单、边界和重复文件保留副本。
- 按实际完成累计容量，部分失败保留剩余项目。回收站容量单列，不冒充释放容量。
- 取消停止后续处理并保留已核对的部分结果；已经完成的删除不回滚。
- 当前结果缓存版本 results_v7，旧版本缓存不沿用；设置变化会使扫描结果失效。
- 无法读取白名单时停止扫描和清理，避免误认为没有保护条目。
