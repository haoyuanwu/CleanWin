## 功能对照与实现

| 管家能力 | CleanWin 本次实现/复用 | 边界 |
| --- | --- | --- |
| 统一体检 | 新增侧栏“全面体检”，五类结果逐项回显 | 默认折叠；重新体检保留旧结果并标记；支持取消和离页继续；仅当前应用生命周期内保留 |
| 硬件信息 | CPU、主板、内存、GPU、磁盘、网卡、音频、显示器、OS | 只读 CIM；权限/接口不可用显示未读取，不伪装正常 |
| 网络基础诊断 | Windows 连通状态、IP、掩码、网关、DNS、DHCP、系统代理与代理环境变量 | 配置和实际外网测试分开；静态 IP/企业代理不计为错误 |
| 延迟与丢包 | 独立“外网探测”：固定微软域名 DNS 解析和 3 次 ICMP | 用户确认后才联网；无 ICMP 回复不直接判定断网；不是测速或完整网络质量评估 |
| 网络处理 | 确认后刷新 DNS 缓存；网络/代理/疑难解答设置入口 | 不自动重设 DNS、静态 IP、DHCP 或删除代理环境变量 |
| 空间与痕迹 | 固定磁盘可用空间、内存概况、最近文件快捷方式计数 | 不把进程工作集相加当物理内存，不清理实际原文件 |
| 垃圾与隐私 | 复用现有一键清理与下载模块；新增“扫描使用痕迹”入口 | 最近文件/跳转列表扫描后仍需在概览手动选择；保留白名单、取消与文件快照保护 |
| 应用与启动 | 桌面软件登记摘要；复用现有可管理启动项规则统计开启/关闭；直达卸载和启动页 | 登记摘要明确不含商店应用；完整列表仍由卸载模块提供；不按未知使用情况推荐删除 |
| 内存与进程 | 复用运行监控入口与现有内存操作 | 不增加持续后台强制整理或终止其他程序的行为 |
| 设置建议 | 查看默认浏览器/PDF/任务栏配置，打开默认应用、任务栏、锁屏、通知及系统启动应用设置 | 不把用户选择第三方浏览器/PDF 当故障；不强制恢复 Edge/Bing/Office |
| 报告 | 可复制本机体检结果 | 含本机配置/IP，按钮提示；代理用户名密码、URL 查询参数脱敏 |

## 未移植的部分

- 微软的应用弹窗拦截依赖其独立插件与服务；Windows“通知与弹窗”设置入口不等于已有同等拦截引擎。本次没有显示虚假的“已开启拦截”。
- 微软 AppUsage 使用数据涉及自己的业务服务与持续统计。CleanWin 当前没有可靠历史使用时长，本次不生成“长期不用”或伪造使用排行，也不暗中开启持续使用跟踪。
- 微软 SmartBoost 后台自动策略没有原样复制。本次只复用已存在的清理与运行监控能力。
- Windows Update 是独立插件，未证实属于此版本全面体检；本次不加入后台更新下载、安装和自动重启。
- 厂商推广型建议不作为问题项。没有移植私有驱动、私有 RPC 或复制微软的实现代码。

因此本次是基于证据的独立功能补齐，并非与微软电脑管家全部模块等价。

## 验证

- 新增体检行为回归：分批结果、取消/重扫、离页继续、失败关闭、代理脱敏、操作确认与窄布局。

- 六段 PowerShell 脚本语法检查无错误；默认体检只读查询与需要用户确认的外网探测相互分开。

## 概览整合（2026-10-22）

独立全面体检导航已取消，原索引 11 转到概览。概览的“开始扫描/重新扫描”和启动自动扫描均通过 AppState.scanOverview 同时执行空间清理与本机体检；AppState 持有体检控制器，离页不取消任务。空间分类和文件明细直接沿用概览列表，增加分类文件数量；硬件、网络、空间概况、应用和设置结果收在默认折叠的“电脑体检”。取消操作覆盖文件与体检两个任务，文件扫描先完成时继续显示体检进度。外网探测和 DNS 刷新仍需独立确认；Windows 磁盘清理入口位于概览顶部图标。


## 系统维护取舍（2026-10-23）

Windows 设置页面已改为直接工具网格：默认应用、通知、任务栏、锁屏、启动应用、存储、更新、恢复。去掉“设置建议”详情、静态无效建议和扫描/刷新按钮，不把用户偏好当异常。启动时只静默读取硬件与网络，不再采集建议。任务与记录页面及全部 UI 入口移除，注册表备份恢复单独留在注册表。
