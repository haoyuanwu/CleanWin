# CleanWin — 轨道控制台

## 设计意图

把磁盘空间、文件分布与运行状态视作可操作的仪表。首页保留星球与轨道；侧边栏保留半叠放结构；数据页面使用低饱和矿物色、精确对齐和安静的留白。独特性集中在轨道视觉，不把每个控件都做成装饰品。

## 基础规范

| 角色 | 色值 / 规则 |
| --- | --- |
| 深墨蓝 | #152B36，侧栏与深色空间 |
| 雾银灰 | #F0F3F4，普通工作区底色 |
| 陶瓷白 | #FFFFFF，数据表面 |
| 深青 | #246B70，主要操作与焦点 |
| 蓝灰 | #516B83，辅助数据 |

中文正文采用 Segoe UI / Microsoft YaHei UI / Microsoft YaHei 系统回退；数字用等宽数字特性，数量与单位保持一组。正文 13–14，辅助 12，页标题 20，主要数据 24–28。不同层级使用 10 / 16 / 24 圆角；结构边界 1.2，焦点 2；按钮通常 40 高，至少 8 间距。

模块背景以相近的银灰、蓝灰、浅青、石色区分，避免彩虹渐变；模块强调色只用于主要动作、焦点和重要数据。危险与警告保留语义色。

## 页面与交互

左侧半叠放导航 → 顶部工具栏 → 数据概况 → 主要内容 → 必要的操作反馈。磁盘与启动项保留无冗余标题的工具界面。首页列表隐藏滚动条；其他页面列表显示可拖动滚动条，保留鼠标滚轮、触控板与键盘滚动。

悬停不改变几何尺寸；焦点明确；选择、过滤和右键动作保持可发现性。菜单只绘制一层选中背景。搜索默认图标，展开后获取焦点，Esc 收起并重置过滤。文件目录统一在资源管理器打开，文件定位不执行文件。

动效分为 140ms 操作反馈、200ms 展开/筛选、360ms 数值变化；系统减少动态效果时显示稳定最终状态。页面切换不重建扫描任务，不清空已有结果，不给后台模块加入持续动画。

## 首页

宇宙背景、星球及扫描轨道为唯一主视觉，色调收敛为墨蓝与月光青。扫描、手动选择和清理完成都反映真实数据。清理确认、取消与成功状态清晰。回收站结果与真正释放的空间分开显示。

## 验证

使用隔离演示数据导出各模块 1000 和 560 内容宽度预览，检查布局、菜单、禁用状态及大列表。运行现有行为回归，不在视觉验证中操作真实文件、注册表或启动项。

设计 Skill 的检索提供了简约风格、Flutter 自适应布局及状态反馈建议；其营销落地页结构不适用于此桌面工具，因此不采用。上表是本项目基于既有用户偏好确定的设计规范。

## 交互层级补充

主要动作使用实色按钮；辅助动作使用浅色填充或文字按钮，避免常驻描边。键盘焦点仍使用清楚的轮廓。列表悬停有底色，选中同时改变底色与左侧标记。下载页顶部仅处理扫描与筛选，选择后底部操作栏展开；取消选择后收起。概况值、筛选、展开和清理结果用短过渡显示状态变化。

## 运行监控

资源卡片使用开口仪表与最近 60 次采样趋势。CPU 和内存卡片可打开趋势详情，显示最低、平均和最高占用。物理内存的已用与可用量独立展示，进程工作集排行可点击筛选；进程工作集含共享内存，不能相加后当作物理内存已用量。温度读取保持原方案。

监控配色按数据角色区分：内存青绿 #247870、CPU 蓝 #3869B3、温度参考暖橙 #A16627，排行辅以紫色区分。趋势面积使用对应浅色，不用同一青色表达所有信息。


## 产品功能归属（2026-10-22）

以 [WORKSPACE_STRUCTURE.md](WORKSPACE_STRUCTURE.md) 为当前导航和功能职责依据。概览只承载空间清理；硬件、网络迁入系统监控，Windows 偏好迁入系统维护，下载迁入文件管理，应用残留迁入应用管理。工作区使用紧凑图标标签、惰性创建和访问后状态保留；侧栏保持半遮布局。


## 系统监控大屏（2026-10-22）

系统监控保留运行监控、硬件信息、网络诊断的原标签索引，并新增独立“进程管理”标签（深链 16）。运行监控与硬件信息采用一致的深墨蓝网格、月光青/雾蓝资源配色与 18px 圆角仪表。
运行监控展示 CPU、内存、真实 CPU 传感器、物理内存已用/可用以及上下行接口吞吐；最近 60 次成功采样曲线可审查资源详情。独立进程页保留内存降序、搜索、前三名筛选、结束确认和系统进程保护。
资源页不调用 Get-Process，只有活动页每秒采样；离开或最小化时暂停采样进程。温度不可用时显示缺失，不以主板温区替代。
网络利用活动非回环/隧道网卡 GetIPStatistics 字节计数差分，按真实采样时间换算；首帧、断线、计数回退、长间隔均重新建立基线。虚拟网卡可能计入，吞吐不是外网测速，不主动发送探测流量。采样失败不能伪报 0 B/s。
硬件仪表复用启动时的本机只读快照，拓扑示意和设备卡片展示配置/读取状态；不把配置容量伪装成利用率。卡片打开可选中、可复制的完整详情。支持刷新及不可读状态。
已导出 1000/560 两种宽度的资源、网络、进程及硬件预览。本机只读采样验证已返回真实上下行速率，且资源采样进程列表为空。
参考：[Windows 接口计数](https://learn.microsoft.com/en-us/dotnet/api/system.net.networkinformation.networkinterface.getipstatistics?view=netframework-4.8.1)。
