CleanWin 是一款 Windows 桌面清理与系统管理工具，集中提供垃圾清理、磁盘分析、下载整理、软件管理和运行监控。

功能包括：

- 统一空间清理：扫描临时文件、浏览器和软件缓存、日志、使用痕迹与回收站，展示分类大小与明细。
- 磁盘空间分析、大文件筛选与重复文件内容校验。
- 下载管理、软件卸载、启动项管理和注册表备份恢复。
- 运行监控、网络速率、硬件信息与基础系统体检。
- 文件白名单、清理确认、任务取消及占用软件选择关闭与尝试恢复。

下载安装：下载下方 `CleanWin-1.0.0-windows-x64-setup.exe` 并运行安装向导。适用于 Windows 10 / 11 x64，安装和运行需要管理员授权。

清理前请核对选中项目。普通缓存删除不可撤销；下载、大文件和重复文件操作使用 Windows 回收站。关闭软件前请保存工作，重新打开软件不代表能够恢复未保存内容。
