# CleanWin 架构

## 定位与页面

Windows Flutter 桌面空间管理工具。概览与一键清理合并为宇宙可视化页面；其他模块使用独立配色、占用图表、图标搜索、自定义下拉及无可见滚动条列表。半遮盖侧栏按功能分类，顶部空白区域支持拖动。

页面包括概览与清理、磁盘分析、大文件、运行监控、软件卸载、启动项、注册表、下载管理、白名单与设置。任务与记录从侧栏底部进入；重复文件从大文件工具栏或设置进入；备份恢复从注册表或设置进入。

界面使用 1.5～2 像素描边、20 像素卡片圆角和 14 像素控件圆角；图表圆环与容量条加粗。标题和列表显示关键数字，重复操作说明通过信息图标悬停查看；设置项用图标和开关表达状态，已选数量、错误与清理风险仍直接呈现。图表筛选、按钮和折叠内容采用短过渡，并遵守系统减少动画设置。小窗口空状态可收缩或滚动，避免挤出列表。

## 数据与服务

| 层 | 职责 |
|---|---|
| models | 清理条目、文件快照、取消令牌、扫描设置与报告 |
| ScanService | 按类别发现、快照、去重、白名单排除、分批权限核对、路径进度 |
| CleanService | 统一清理：边界、文件变化、链接、保护路径及保留副本验证，取消与部分结果 |
| recycle_service | 在后台通过 Windows IFileOperation 回收个人文件，失败不永久删除 |
| disk_services | 磁盘统计、大文件流、缓存与读取诊断 |
| DuplicateService | 大小预筛、后台 SHA-256、硬链接排除、删除前复核 |
| FileMoveService | 暂存副本、内容核对、不覆盖提交、最后处理源文件 |
| UninstallService | 安装身份、正常卸载向导、退出码和安装记录核对 |
| RegistryScanService / RegistryBackups | 支持值的扫描、备份、单值恢复与防覆盖 |
| WhitelistService | 严格读取、暂存写入后提交，保存失败维持原有保护 |
| ActivityJournal / TaskBoard | 最近操作记录与运行任务、取消入口 |
| AppState | 设置、扫描及清理状态、结果缓存、下载选择与卸载列表 |

## 处理流程

扫描依次发现候选 → 记录文件大小和修改时间 → 后台分批核对操作权限 → 分类逐步回显。取消保留已核对的部分结果。快速和深度模式改变软件发现范围，不改变默认保守勾选原则。

清理从用户已选择的快照开始，逐文件重新验证 → 删除缓存或回收个人文件 → 更新剩余项 → 保存历史。回收容量和释放容量分开报告；取消停止后续处理。没有后台强制结束占用程序。

卸载启动正常向导并等待退出，结合退出码核对同一安装身份。取消、失败、需要重启或无法核对时分别反馈，未核实的项目留在列表。列表五分钟内重用；强制刷新保留旧列表。

磁盘图以字节面积分割，不用对数缩放；显示未能读取的位置。强制刷新清除相关旧统计，列表比较刷新前后同名子目录的容量变化。

磁盘分析按目录维护独立任务与当前会话快照。返回上级、切换磁盘或离开模块不会取消扫描；再次打开运行中的目录接回进度，完成的目录直接回显暂存结果。后台目录完成只更新其自身快照，避免覆盖正在查看的其他目录；仅停止按钮、任务中心取消或退出程序会停止任务。

## 性能与持久化

遍历采用异步目录读取，SHA-256、原生回收及权限检查在后台执行。页面大列表按需构建并分页，路径更新节流。缓存编码及大文件列表写入使用后台路径和独立暂存位置，防止并发临时文件冲突。安全设置和保护信息必须保存成功后才改变有效状态。

运行监控约每秒采样，按工作集内存降序；离开页面停止采样。趋势保留最近 60 个成功样本，温度作为参考。结束进程前重新核对 PID/名称并保护系统核心进程；工作集整理只针对本程序。

运行监控使用紧凑工具栏与指标卡片，进程行高 50，优先保证列表可用高度。窗口保留自定义外观，启用原生可缩放样式；Flutter 子窗口边缘命中透传给父窗口，八个方向均可拖动缩放。边缘宽度与最小尺寸随 DPI 调整，最大化限制到当前屏幕工作区，避免遮挡任务栏。正常最小尺寸为 900×600 逻辑像素，较小工作区按实际屏幕限制。

原生窗口处理依据 [Microsoft 窗口样式](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-styles) 与 [WM_NCHITTEST](https://learn.microsoft.com/en-us/windows/win32/inputdev/wm-nchittest)。本次窗口源文件通过原生编译检查，未链接替换正在运行的程序；拖动缩放的实际体验需在重新构建启动后核对。

缩放重绘不再在每次 WM_SIZE 中重建窗口区域或重设 DWM，避免窗口区域变化触发额外位置／重绘消息。父窗口裁剪子窗口绘制并跳过背景擦除，取消 CS_HREDRAW／CS_VREDRAW；子窗口更新尺寸后请求不擦除背景的异步绘制，最小化时不缩成零尺寸。DWM 外观仅在初始化及合成／主题变化时配置。此次修改通过原生文件编译，闪屏改善仍需新版窗口实际拖动验证。接口参考：[SetWindowRgn](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowrgn)、[MoveWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-movewindow)。

## 验证与兼容边界

测试涵盖服务安全边界、状态交互、任务取消与宽窄布局；原生回收另以自动创建的小文件验证。真实软件卸载与注册表修改没有通过测试自动执行。各类缓存无法仅凭目录名完全识别，清理范围详见 [SCAN_AUDIT.md](SCAN_AUDIT.md)。
