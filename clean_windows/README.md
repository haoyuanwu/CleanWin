# CleanWin

CleanWin 是一款面向 Windows 的桌面清理与系统管理工具，将垃圾清理、磁盘空间分析、下载整理、软件管理和运行监控集中在一个界面中。通过分类列表、空间地图和实时图表，帮助你了解空间去了哪里，再按需处理。

支持扫描系统临时文件、浏览器与软件缓存、日志和回收站；也可以查找大文件与重复文件、管理启动项、查看硬件信息和执行基础系统体检。清理前展示范围与影响，支持白名单和任务取消，占用文件可按提示选择关闭相关软件并尝试恢复。

## 下载与安装

前往 [GitHub Releases](https://github.com/haoyuanwu/CleanWin/releases/latest) 下载 `CleanWin-版本号-windows-x64-setup.exe`，运行安装向导即可。支持 Windows 10 / 11 x64；安装和运行需要管理员授权。

## 软件亮点

- 统一清理入口：集中查看各类垃圾的大小与明细，显卡缓存默认不勾选。
- 空间可视化：磁盘地图、大文件筛选与重复内容校验，方便定位空间占用。
- 下载整理：按来源查看下载文件，支持打开位置、移动与回收站删除。
- 系统管理：软件卸载、启动项管理、注册表备份与恢复、系统设置快捷入口。
- 实时了解电脑：进程资源趋势、网络速率、硬件信息和基础体检结果。
- 占用处理：列出关联软件，可单独或批量选择关闭；清理前再次确认需要关闭的程序，并尝试重新打开。

## 功能

| 模块 | 当前能力 |
|---|---|
| 概览与清理 | 统一空间清理、实时扫描路径、分类折叠、扫描与清理取消、清理影响说明 |
| 磁盘分析 | 按字节面积绘制地图、地图／列表切换、扫描中返回或切换磁盘、后台完成暂存结果、再次进入直接回显、未读取位置提示、同目录刷新增长对比 |
| 大文件 | 完整扫描、分页展示、类型／修改时间／路径筛选、指定目录、回收站删除 |
| 重复文件 | 指定目录，大小预筛后按 SHA-256 校验内容；手动选择副本，至少保留一份 |
| 下载管理 | 系统下载 ≥10MB 文件及目录，加上腾讯／360 软件管家的下载包（按来源汇总），手动选择，回收站删除，打开位置／复制路径／移动文件 |
| 软件卸载 | 进入即展示已有结果；五分钟内重进复用结果；手动刷新保留列表；正常卸载向导及退出码、安装记录核对 |
| 启动项 | 分类展示启动来源，手动管理；进入页面时加载 |
| 注册表 | 仅列出支持清理的失效值，分类默认折叠；逐值备份、预览恢复，恢复时拒绝覆盖已有值 |
| 运行监控 | 约一秒采样、内存排序、趋势与暂停；结束进程前确认并保护核心进程；工作集整理仅限本程序 |
| 白名单 | 文件／目录保护，写入失败保留原有保护，读取失败停止清理 |
| 任务与记录 | 侧栏底部入口；查看运行任务、取消支持的任务、最近 200 条操作记录、注册表备份及 Windows 回收站 |

## 扫描和清理边界

- 空间清理集中展示缓存、日志、使用痕迹和当前用户回收站；下载文件在下载管理中单独审核。
- 已发现的常规垃圾默认勾选，显卡缓存默认不勾选；下载、应用残留、注册表等专项操作仍需手动审核。缓存名称只能提供候选线索，不能证明所有内容都适合删除。
- 保留浏览器密码、书签、Cookie、聊天数据、安装修复资料、已知开发依赖和离线资源。本程序目录及系统／安装目录中的个人文件操作受保护。
- 清理只处理扫描清单；白名单、链接、范围外路径、扫描后变化的文件均跳过。占用软件经用户选择后才关闭；不允许关闭或无法安全处理时跳过对应文件。软件重启是尽力恢复，不能保证恢复未保存的工作内容。
- 下载、大文件及重复文件送入 Windows 回收站；回收失败不会改为永久删除。回收站容量与实际释放容量分开统计，清空回收站后才释放对应空间。
- 常规缓存清理为直接删除；任务取消会停止后续处理，已经完成的删除不会回滚。文件移动先复制、核对内容，再处理原文件，不覆盖已有目标。
- 注册表恢复仅针对本工具支持的备份值，不能恢复已删除的普通缓存文件。权限不足的内容保留并提示。

## 开发和构建

安装 Flutter Windows 桌面开发环境后，可使用 run.ps1 或 run.bat 启动。启动脚本会关闭已有的本程序进程，执行前请结束当前任务。

~~~powershell
flutter pub get
flutter run -d windows
flutter build windows --release
~~~

发布产物：build/windows/x64/runner/Release/clean_windows.exe，分发时需保留同目录依赖与 data。

若环境缺少 ProgramFiles(x86)，先修正当前进程的 Windows 环境变量。构建文件被占用时，先正常退出正在运行的应用。

## 验证

~~~powershell
flutter analyze
flutter test
flutter test --dart-define=UI_PREVIEWS=true
~~~

最后一项在本机 Windows 字体可用时导出页面预览到 .dart_tool/ui_previews。文件操作测试仅使用隔离目录；卸载、注册表操作采用模拟执行器和脚本解析验证。


## 安装与管理员权限

CleanWin 的安装、卸载和程序运行均要求管理员权限。普通启动时由 Windows UAC 请求授权，不同意则不启动。安装到 Program Files，快捷方式和直接打开 EXE 都使用相同权限要求。

开发调试请以管理员身份运行 Flutter Manager 或终端；`run.ps1` 会检查该要求。原生清单变更需重新构建，热重载或热重启不会改变已有进程权限。

Windows Release 构建完成后，安装 Inno Setup 6.3+，运行 `powershell -File scripts/package-windows.ps1` 生成安装包。脚本先验证构建 EXE 的嵌入式管理员清单。完整说明见 [安装与运行权限](docs/ADMIN_SCAN.md)。
